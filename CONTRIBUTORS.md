# Contributors

IDKMesh recognizes every real contribution here, not only merged code. A
question that reveals confusing documentation, an honest "I got stuck here"
report, a reviewed pull request, or a line of code are all useful project
evidence, and all of them earn a place on this wall. See
[`docs/community/CONTRIBUTOR_QUICKSTART.md`](docs/community/CONTRIBUTOR_QUICKSTART.md)
for how to start.

Entries are added as contributions land, in no particular ranking order. This
file follows the [All Contributors](https://allcontributors.org) emoji-key
convention.

## Emoji key

| Emoji | Meaning |
| --- | --- |
| 🐛 | Bug/gap reports |
| 💻 | Code |
| 📖 | Documentation |
| 🤔 | Ideas & planning |
| 👀 | Reviewed pull requests |
| ⚠️ | Tests |
| 🔬 | Research |
| 🚇 | Infrastructure |
