What is IDKMesh?

IDKMesh asks whether many humans and AI agents can turn uncertain goals into trustworthy software and research without pretending that raw output is knowledge.

Goal → bounded Work Unit → isolated attempts → independent verification → evidence → explicit integration decision.

The project deliberately separates generation from acceptance. A successful worker, popular proposal, or large swarm does not automatically become canonical truth.

Why now?

Agents can generate quickly

Generation capacity is growing faster than trustworthy review capacity. IDKMesh treats verification debt and evidence quality as first-class constraints.

Different agents fail together

More votes are not automatically more independent evidence. The project measures verifier reliability, dependence, and failure correlation.

Open source needs coordination

The repository itself is an experiment in bounded work, public evidence, reproducible decisions, and community growth without activity-count Goodharting.

The operating principle

Optimize verified useful work per unit of scarce human attention and compute—not commits, agent count, stars, or activity volume.

IDKMesh is intentionally unfinished. The repository is the public laboratory, and well-supported disagreement is a contribution.
