## Definition of a healthy merge queue

Prefer:

- one canonical PR per responsibility;
- exact-head evidence;
- clean current-main replacements instead of stale stacks;
- drafts only for real external blockers;
- public negative evidence;
- closed superseded branches as provenance;
- no one-shot evidence-generation workflows on `main` unless they become genuinely reusable infrastructure.

A useful direction for integration health remains:

```text
IntegrationYield =
  verified durable changes merged
  ---------------------------------------------
  reviewer attention + conflict debt + rework
```

with penalties for stale review-ready PRs, duplicated responsibility, description/diff mismatch, and unverified privileged workflows.
